# Enter Messenger

Новый слой проекта — desktop-клиент Tauri + React в `desktop/` и автономный Rust-сервер в `server/`.

```bash
cd desktop
npm install
npm run dev
npm run tauri dev
```

Сервер запускается из корня проекта:

```bash
cargo run --manifest-path server/Cargo.toml
```

Сервер профиля задаётся вручную в переключателе профилей. Профили хранятся локально, поэтому аккаунты на разных серверах не смешиваются.

В клиенте есть компонентная оболочка чата, локальный список профилей, composer, настройки приватности и рабочий E2E v1. Клиент создаёт device keys локально, публикует только открытые ключи и шифрует сообщения AES-256-GCM. Сервер хранит только ciphertext и отдаёт зашифрованные сообщения обратно для локальной расшифровки.
